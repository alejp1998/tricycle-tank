📖 Tricycle Tank — Project Guide

🎓 The Project

Tricycle Tank was a university (SDG2) robotic-combat game written in C for a Raspberry Pi. A tricycle-drive tank with a dual-servo turret fires an IR "laser" at opponents; the last tank standing wins. All hardware control goes through wiringPi: hardware PWM on the wheels (pins 18/19), software PWM on the turret servos (17/27), a softTone buzzer for sound effects (pin 23), the laser on pin 9, and a rising-edge interrupt on pin 11 for hit detection.

🧠 The Architecture

The game runs four parallel finite-state machines on a shared 10 ms clock: the xbox360 FSM (controller input, debounced), the player FSM (melody playback — Despacito, Game of Thrones, Tetris and Star Wars on the buzzer), the ruedas FSM (wheel PWM + steering) and the torreta FSM (turret servos, IR shot and shoot-timeout). An Xbox 360 controller drove everything through a Python bridge (xbox360controller) writing a key turret posX posY file the C code polls.

🎮 Controller Mapping (original)

  • Left stick — move wheels · Right stick — turret servos
  • Right trigger — fire laser · X — reload (10-bullet magazine)
  • D-Pad — select melody · A/B — play / stop melody
  • START — begin game · Y — end game

🖥️ This Web Edition

A faithful playable port: the same 10-bullet magazine (auto-reloads when empty or press R), the same 10 hits to win, 5 hull points to lose, arena obstacles that absorb laser fire, three AI tanks that hunt you, and the real Tetris and Star Wars note tables from the C source played through WebAudio. Drive with WASD/arrows, aim with the mouse (or Q/E), fire with click/Space.
